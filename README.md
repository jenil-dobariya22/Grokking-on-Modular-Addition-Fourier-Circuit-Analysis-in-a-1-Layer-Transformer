# Grokking-on-Modular-Addition-Fourier-Circuit-Analysis-in-a-1-Layer-Transformer
Grokking on modular addition, (a+b) mod 113: a 1-layer transformer trained with TransformerLens, with Fourier circuit analysis showing it uses 5 key frequencies, verified by causal ablations. Reproduces Nanda et al. (2023).
